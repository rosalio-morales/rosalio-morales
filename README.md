### 🏁 Proyecto destacado: Cloud POS & ERP multi-tenant

Punto de venta e inventario en la nube para refaccionarias y comercios: cada negocio tiene sus datos aislados, cobra con MercadoPago y paga una renta mensual por la plataforma.

<p align="center">
  <a href="https://github.com/rosalio-morales/cloud-pos-erp-demo">
    <img src="https://github.com/rosalio-morales/cloud-pos-erp-demo/raw/main/docs/venta.gif" alt="Venta completa en la demo: búsqueda, carrito, cobro y ticket" width="800">
  </a>
</p>

- **Stack:** React 19, Node.js + Express 5, MongoDB Atlas, MercadoPago (Checkout Pro + webhooks firmados)
- **Multi-tenant:** aislamiento por negocio con JWT ligado al tenant
- **Pagos:** stock apartado de forma atómica, total calculado en el servidor, webhook idempotente
- **Despliegue:** Netlify + Render + GitHub Actions (CI y reinicio nocturno de la demo)

👉 **[Probar la demo](https://refaccionaria-vargas-demo.netlify.app)** (cuentas de prueba en la vitrina) · **[Ver la vitrina del proyecto](https://github.com/rosalio-morales/cloud-pos-erp-demo)**
